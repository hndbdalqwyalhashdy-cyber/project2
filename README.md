## 2. نبذة عن الفندق والمنتجع — About the Hotel & Resort

**فكرة الفندق والمنتجع:** ملاذ ساحلي فاخر حيث يلتقي البحر بسحر الطبيعة — Where the Sea Meets the Beauty of Nature. A coastal sanctuary made for moments that stay with you.

## 5. المميزات والوظائف التفاعلية — Features & Interactive Functions

**الهيكل الخطي (Dynamic via JS):** الهيرو، الأقسام، البطاقات، الحالات، الألات — تُنشأ في المتصفح من المقاطع (templates) في `js/main.js` حسب اللغة (A = window.Ofoq.t).

**الوظائف التفاعلية:**

- **اللغة والثيم (`language.js`, `theme.js`):** تبديل ar/en (lang/dir تلقائية + validation messages)؛ ثيم فاتح/داكن مع transitions عبر جميع الصفحات؛ الحفظ في localStorage (`ofoq-language`, `ofoq-theme`).
- **التنقل (`navigation.js`):** قائمة جوال (menu toggle + aria-expanded + ARIA labels)؛ زر العودة إلى أعلى (≤500px) + sticky header; back-to-top.
- **إدارة الغرف (`rooms.js`):** محفظة الغرف مع الأسعار/المواصفات؛ ترشيح حسب النوع (Room/Suite/Villa)، بحث بالاسم، ترتيب حسب السعر؛ أزرار «اكتشف الغرفة ←/Explore room →» إلى تفاصيل الإقامة.
- **نظام الحجز (`booking.js`):** نظام ثلاثي الخطوات (مستوى: 1 الإقامة، 2 بياناتك، 3 التأكيد) مع تحقق مدخلات (required/minlength/min-dates)؛ ملخص الإقامة (غرفة/ليالي/ضيوف/الإقامة/الضريبة 15%/الإجمالي التقديري)؛ حفظ طلب الحجز في localStorage (`ofoq-bookings`) + إعادة توجيه عند تفريغ الشكل.
- **المعرض (`gallery.js`):** نافذة تكبير (lightbox) مع عودة سابقة/تالية (أسهم، Escape)، زر مقطع + حصر Tab داخل النافذة، إرجاع التركيز على الفتح، تغيير عنوان الصورة، حجل تمرير الخلفية، دعم أيقونات هيئة (FakeIcons — w=1800).
- **نماذج التواصل (`contact.js`):** نماذج تواصل + اشتراك نشرة (newsletter)؛ رسائل تحقق تلقائية بلغة مطابقة (Toast «شكراً لتواصلك...» / «أُضيف بريدك إلى قائمتنا»).
- **الحركات (`animations.js`):** ظهور متتابع (IntersectionObserver)، مفاوضات حركية خفيفة (requestAnimationFrame)، باراكسال خفيف لهيرو (max ±28px)، تيلت على بطاقات الغرف، تواقف مع `prefers-reduced-motion`.
- **الفوتر:** نماذج نشرة، بيانات الاتصال، روابط اجتماعية، حقوق نشر © — تُكمّل بعناوين عربية/إنجليزية، عمود «موقعنا | Our Location» (أملج، منطقة تبوك) على الفوتر.
- **صفحة 404:** نص موحّد («ربما أخذتك الأمواج إلى مسار آخر...») + زر عودة.

## 6. التقنيات المستخدمة — Technologies

- **HTML5:** صفحات أوامر جاهزة (shells) مع `data-page`، دلالات ARIA، أيقونات SVG داخلها.
- **CSS3 (vanilla, no framework):** Custom Properties، Grid، `aspect-ratio`، `object-fit: cover`، `clamp()`، `@media`، `prefers-reduced-motion`، `View Transitions` (`startViewTransition` — على HTTP(S) فقط)، keyframes للحركات الجزئية.
- **JavaScript (Vanilla ES6+):** بدون مكتبات خارجية (لا jQuery/React) — localStorage (`ofoq-language`, `ofoq-theme`, `ofoq-bookings`, `ofoq-messages`, `ofoq-newsletter`), IntersectionObserver, requestAnimationFrame, URLSearchParams, matchMedia.
- **الخطوط:** Google Fonts — Cairo (Arabic) + Montserrat (English) — وزن 400–700.
- **الصور:** عبر `photo(id, width)` في `main.js` → `https://images.unsplash.com/photo-<id>?fit=crop&w=<width>&q=82&fm=webp` — صور عرض تجريبية (Unsplash)، تحميل كسول (`loading="lazy"`)، عرض متغير (w=900/800/700/1100/2200)، fallback عند فشل الطلب (alt «الصورة غير متاحة حالياً»).
- **الخادم (Cloudflare Pages):** ثابت (Static) — بدون Node/PHP/ASP — SPA غير مكتمل (نموذج حجز، واحد)، لذا لا توجد نقاط نهاية خاصة به (API) حتى الآن.

**الخطوط:**

- `--font-ar: "Cairo", sans-serif` (عربي) — Google Fonts.
- `--font-en: "Montserrat", sans-serif` (إنجليزي).
- الأوزان: 400–700 (`--weight-regular` … `--weight-bold`).

**المساحات والأبعاد:**

- الأساس: 4px (`--space-1` … `--space-20`); `--section-space` (4–8vw, 4–6rem); `--container-width: 73.75rem`.
- الحدود: `--radius-sm` (0.5rem) … `--radius-2xl` (1.75rem), `--radius-pill` (999px).
- الظلال: `--shadow-sm/md/lg`, `--shadow-focus`.

**حجم النص:**

- `--text-xs` (0.75rem) … `--text-display` (clamp 3–6.25rem)، `--text-404` (clamp 6–13rem).
- `--line-body: 1.75`, `--line-heading: 1.3`.

**الأزرار (`components.css`):** `.btn` جذوره، `.btn-primary` (gold)، `.btn-secondary` (turquoise)، `.btn-outline`, `.btn-transparent`, `.btn-icon`؛ نقاط hover/active + خروج مرئي + انتقالات (`--transition-base`).

**البطاقات والحقول:** `.editorial-card` (بطاقات الغرف/الحدائق/بطاقات الإقامة) مع السطح `--surface-raised`, الحدود `--line`, زوايا `--radius-xl`; `.editorial-card img` في `aspect-ratio: 16/10`, `object-fit: cover`, `transform: scale(1.035)` عند التحويم. حقول: `.field` (input/select/textarea) مع ملحقات `.field.full`.

**أجواء الصور:**

- بطاقات الغرف (rooms): صورة `object-fit: cover`، زخرفات hover (توهج ذهبي عند التحويم على البطاقة — `.room-card::after`)، شرفة فيها نصوص مخصصة (title/type/price).
- بطاقات الحدائق (gardens): العنوان التوصفي `image-caption` (رأس بطاقات أخرى).
- بطاقات الخضراء (split-band — المساحات الخضراء): `min-height: 540px`, `object-fit: cover`.
- بطاقات الحجز: `.booking-form` (نموذج ثلاثي الخطوات)، `.booking-summary` (ملخص جانبي — `position: sticky`, `top: 100px`)، قاعدة glass.
- Lightbox: `.lightbox img` — `max-width: min(100%, 1100px), max-height: 82vh`.

## 10. النشر على Cloudflare Pages — Deployment on Cloudflare Pages

المشروع موقع ثابت؛ لا يحتاج Node.js أو حزم أو خطوات بناء. `index.html` في جذر المشروع، وCloudflare Pages يتعرف تلقائياً على `404.html` في جذره.

### 1. ارفع المشروع إلى GitHub

```bash
git init
git add .
git commit -m "Prepare OFOQ HOTEL for Cloudflare Pages"
git branch -M main
git remote add origin https://github.com/<USERNAME>/<REPOSITORY>.git
git push -u origin main
```

(يتحقق من وجود `index.html` + `404.html` في الجذر مع `css/`, `js/`, `assets/`, `robots.txt`).

### 2. اربط GitHub بـ Cloudflare Pages

- **Workers & Pages → Create application → Pages → Connect to Git** (GitHub، صلاحية الوصول، اختر المستودع → Begin setup).
- الإعدادات:

| الإعداد | القيمة |
|---|---|
| Framework preset | None |
| Production branch | `main` |
| Build command | `exit 0` |
| Build output directory | `.` |
| Root directory | اتركه افتراضياً |

- بدون متغيرات بيئة (لا توجد بناء/عمليات خادمية).
- **Save and Deploy** → انتظر النشر، ثم افتح عنوان `*.pages.dev`.

### 3. تحقق بعد النشر

- افتح: home (index.html), rooms, room-details, gardens, dining, facilities, gallery, booking, contact, privacy, terms.
- اختبر `https://<PROJECT>.pages.dev/robots.txt`، `/assets/logo/ofoq-mark.svg`.
- افتح مسار غير موجود (مثل `/check/not-found`) — يجب أن تظهر `404.html`.
- تحقق أن صور Unsplash تُطلب بصيغة WebP (سجل الطلبات في Cloudflare).
